# 🎮 Pokemon App

เว็บแอปพลิเคชันแสดงข้อมูล Pokemon ทั้ง 1,351 ตัว พัฒนาด้วย Next.js และ MUI

## ✨ Features

- แสดงรายการ Pokemon ทั้งหมด 1,351 ตัว
- ดึงข้อมูลทีละ 100 ตัว พร้อม Pagination
- หน้ารายละเอียด Pokemon แต่ละตัว ได้แก่ ชื่อ รูป ประเภท สถานะ วิวัฒนาการ และเสียง
- Loading Animation ขณะรอข้อมูล
- Responsive รองรับทุกขนาดหน้าจอ

## 🛠️ Tech Stack

- Next.js 16
- React 19
- TypeScript
- Material UI (MUI)
- PokeAPI

## 🚀 วิธีติดตั้งและรัน

1. Clone โปรเจค
git clone https://github.com/nattapon1123/Pokemon007.git
cd Pokemon007

2. ติดตั้ง Dependencies
npm install

3. รันโปรเจค
npm run dev

4. เปิดเบราว์เซอร์ที่ http://localhost:3000
